# Student Expense Tracker

A simple Python command-line app that helps students track their daily expenses, save them to a file, and see a category-wise summary.

## Problem
Many students don't know where their money goes each month. This app makes it easy to record and review spending.

## Features
- Add an expense (amount, category, note)
- View all expenses in a table
- See total spent and category-wise summary
- Data is saved in `expenses.json`, so it is kept after closing the program

## How to run
```
python expense_tracker.py
```

## Built with
Python 3 (`json`, `os`, `datetime` modules)
